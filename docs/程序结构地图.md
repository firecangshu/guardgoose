# 护院鹅 · 程序结构地图

> 按「源文件 / 剧本 / 真数据引入 / 真实数据库落盘 / 缓存与临时产物」五类梳理。
> 本文件只做索引，不改动任何运行链路（生成于 2026-08-08）。

## 一、运行链路一览

```
ESP32 板子 ──串口──► hw/bridge.py（采集/FFT/锁频）
                         │ POST /ingest/sample（真数据引入的唯一入口）
                         ▼
                    edge/server.py（FastAPI，8000 端口）
                         │ 状态机判定
                         ▼
        edge/state_machine.py + fall_detect.py + guardian.py
                         │ 事件入库 + WebSocket 广播
                         ├──► waveguard.db（运行事件库）
                         └──► h5/dist（子女端页面，同端口托管）

演示链路（无硬件）：edge/server.py 内置演示循环 ──读取──► replay/scenarios/*.json
```

## 二、核心源文件（改算法/改产品只动这里）

### 后端（edge/）
| 文件 | 职责 |
|---|---|
| `server.py` | FastAPI 主服务：样本闸门、演示循环、救护链、API/WS、托管 h5/dist |
| `state_machine.py` | SampleProcessor 状态机：Zone 分级、三态语义、双证据确证链 |
| `fall_detect.py` | 跌倒三分类检测器（Type A/B/C） |
| `guardian.py` | 监护策略：语音确证链、救护链顺位、升级规则 |
| `config.py` | 全部阈值参数（STILL_MAX/ACTIVE_MIN/SPIKE_MIN 等，调参入口） |
| `medical.py` | 病史档案与基础病修正（只收紧不放宽） |
| `db.py` | SQLite 事件/日志存取（waveguard.db） |
| `protocol.py` | 前后端消息协议定义 |
| `voice.py` | 语音确证会话管理 |

### 硬件层（hw/）——真数据引入
| 文件 | 职责 |
|---|---|
| `bridge.py` | **真数据引入主程序**：串口采集→信号处理→POST /ingest/sample；含开机自检、`--session-label` 测试落盘 |
| `signal_proc.py` | 活动强度/呼吸 FFT 锁频/底噪估计（算法核心） |
| `csi_parser.py` | CSI 串口帧解析 |

### 前端（h5/src/）
| 文件 | 职责 |
|---|---|
| `views/HomeView.vue` | 守护页（实时信号/告警卡/语音确证面板/案情小结） |
| `views/EventsView.vue`、`ProfileView.vue`、`SetupView.vue`、`OnboardingView.vue`、`LoginView.vue` | 事件库/档案本/接入设置等页面 |
| `stores/guardian.ts` | WS 消息消费与全局状态 |
| `services/api.ts` | REST 封装 |

### 启动器与入口
| 文件 | 职责 |
|---|---|
| `run_edge.py` | 后端入口（uvicorn 拉起 server.py） |
| `启动子女端.bat` → `tools/launch_guardian.py` | 一键启动：拉起后端 + PyWebView 独立窗口 |
| `信号测试播放器.bat` → `tools/launch_viewer.py` | CSI 查看器独立进程 |

## 四、真数据引入路径（真实硬件数据怎么进系统）

1. **正式入口**：`hw/bridge.py` → `POST /ingest/sample`（需先开「真实接入」闸门，否则 403 拒收）
2. **实验采集**：`experiment_test.py`（控制变量实验 F1-F4/B1-B4，结果落 `test_results/*.json`）、`observe_csi.py`（裸观察）
3. **回放引入**：`hw/bridge.py --replay xxx.csv`（历史原始帧重新走全链路）

## 五、真实数据库落盘（便于优化算法的内容）

| 位置 | 内容 | 说明 |
|---|---|---|
| **`test_data_db/sessions/`** | 新真机测试逐秒 CSV + summary.json | bridge 加 `--session-label` 自动落盘，退出自动总结；note 字段人工补注 |
| **`test_data_db/legacy/`** | 历史测试归档（7/31 三轮、8/6 联调、控制变量实验 28 轮） | `tools/import_legacy_tests.py` 生成；原始大文件只引用不复制 |
| **`test_data_db/report.md`** | 全库规律分析报告 | `tools/analyze_test_db.py` 重新生成 |
| `test_results/` | 实验 JSON 结果 + 实验日志 md | 本地留存（gitignore，已归档进 test_data_db） |
| `测试数据/`（仓库外） | 三轮原始 CSI 帧 CSV | legacy/meta.json 里索引引用 |

**优化算法的工作流**：测试落盘 → 补 note → analyze 出 report → 对照锁频率/底噪/运动比找规律 → 改 `edge/config.py` 或 `hw/signal_proc.py` → verify 脚本回归。
