层级技术说明
前端框架原生 JS（无框架）轻量、无构建步骤、直接部署
CSS 方案CSS 变量 + BEM 命名双主题切换、组件化样式

数据库SQLite零配置、文件级、够用
AI 引擎Qwen-plus API医学推理 + 结构化决策
硬件通信HTTP POST / MQTT（规划）ESP32 上报 CSI 数据
